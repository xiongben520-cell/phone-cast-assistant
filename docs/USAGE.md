# 使用说明

```text
﻿手机投屏助手  v1.5
================================================

【两种连接方式，任选其一】

  ■ 有线（数据线）—— 最稳、画质最好，推荐日常用
  ■ 无线（Wi-Fi）  —— 不用线，走动方便

  程序默认「自动」：插着线就用有线，没插线就用无线。
  也可以手动锁定「有线 USB」或「无线 Wi-Fi」。

================================================
【解压即用】
把整个「手机投屏助手」文件夹解压到任意位置，
双击 app\手机投屏助手.exe 启动。
不需要安装 Python / adb / scrcpy。

================================================
【有线连接：三步搞定】

1. 手机开「USB调试」
   设置 → 关于手机 → 连点「版本号」7 次（开启开发者选项）
   设置 → 开发者选项 → 打开「USB调试」

2. 用数据线把手机连到电脑
   · 必须是能传数据的线（有些线只能充电，插上没反应）
   · 手机弹出「允许USB调试吗？」→ 点「允许」
     建议勾选「一律允许使用这台计算机进行调试」，以后不用每次点

3. 电脑程序里点「刷新」→ 选到 [USB 有线] 的设备 → 点「连接并投屏」

  程序上方会实时显示有线状态：
    有线: 已连接 (序列号)                    → 可以投屏了
    有线: 已插入，请在手机上点「允许USB调试」 → 去手机上点允许
    有线: 未检测到设备                       → 线没插好或不是数据线

有线模式会在连接时自动测一次实际带宽，
按带宽的 80% 决定视频码率（实测约 340 Mbps → 用 273 Mbps），
帧率固定 60。所以换线、换 USB 口后画质会自动适配，不用手动调。

================================================
【无线连接：需要先配对一次】

1. 手机：设置 → 开发者选项 → 无线调试 → 打开
2. 手机和电脑连同一个 Wi-Fi

然后任选一种配对：

■ 方式一（推荐，最简单）：二维码扫码
   1. 手机：无线调试 → 「使用二维码配对设备」
   2. 电脑程序里点「二维码扫码」页签 → 点「生成二维码」
   3. 手机对着电脑屏幕扫一下就自动配对并连接

■ 方式二：手动填配对码
   1. 手机：无线调试 → 「使用配对码配对设备」
      会显示 IP 地址、端口、6 位配对码
   2. 电脑程序里分别填进 IP / 端口 / 配对码 → 点「开始配对」
   3. 手机会弹「允许配对」，点允许（程序界面会显示还剩多少秒）

配对只需一次，以后打开程序会自动连上。

★ 配对后连不上 / 要等一分钟？
  配对（交换密钥）和连接是两步。连接端口要靠 adb 的 mDNS 广播发现，
  广播有时要 30–60 秒才出现，这段时间界面会显示「已等 Ns / 最多 Ns」。
  想立刻连上，用最快的一条路：
    - 手机：无线调试 主页面会显示「IP 地址和端口」，例如 192.168.1.8:37105
    - 把它填到程序里的「已配对？直接连」→ 点「直接连接」，通常 1–2 秒就上
  （这个办法也适用于以后每次打开程序发现设备慢的情况）

无线也会在连接时实测一次带宽，按 80% 决定码率（上限 30 Mbps）。
Wi-Fi 信号差时会自动降码率保流畅，画面不会卡死。

================================================
【通用操作】
· 点「连接并投屏」→ 电脑上出现手机画面，声音从电脑耳机输出
· 连接时不再改动手机的音量、静音状态，保持你原来的设置
· 手机默认保持亮屏，方便看锁屏界面、输密码、点确认框
· 想让手机灭屏省电：点「手机：亮屏」→ 变成「手机：黑屏」
  （只关屏幕面板，仍在投屏、不锁屏；要操作时再点回来）
· 「投屏置顶：开/关」：让投屏窗口永远压在其他窗口上面，
  也可以点快捷键贴图标题栏的「○/● 置顶」
· 「贴图跟随：开/关」：控制快捷键小抄是否跟着投屏窗口走
· 拔掉数据线 / 断开 Wi-Fi 时程序会提示，恢复后点「刷新」

================================================
【常见问题】

· 有线插上了但程序里没有设备
  → 手机「USB调试」是否打开
  → 手机是否弹出了「允许USB调试」，点允许
  → 换一根能传数据的线试试
  → 部分系统要在「USB连接方式」里选「传输文件(MTP)」

· 提示 unauthorized（未授权）
  → 手机上点了「拒绝」，去开发者选项里「撤销USB调试授权」，再重新插线

· 锁屏/输密码时画面里看不到密码框，或鼠标点了没反应
  → 先点「手机：亮屏」把屏幕点亮（黑屏状态下安全界面不渲染、触摸会被系统丢弃）
  → 小米手机必须在「开发者选项」里打开「USB调试（安全设置）」，
    否则系统禁止模拟点击锁屏、支付密码等安全界面（需要登录小米账号）
  → 点一下投屏窗口让它获得焦点，再用鼠标操作

· 有画面但没声音
  → 手机关闭蓝牙（蓝牙会抢走音频）
  → 点「声音自检」听一声提示音
  → 手机媒体音量建议 60%（程序里有「设为 60%」按钮）

· 无线模式画面卡顿
  → 手机和电脑尽量连 5GHz Wi-Fi，别隔太多墙
  → 或者直接用数据线，有线不会卡

· 程序被安全软件拦截
  → 打包工具生成的 exe 偶尔被国产杀软误报，加为信任即可

· 刷新一直“找不到设备”，日志提示 adb server 无法连接（v1.6.1 已自动处理）
  → 电脑上 Hyper-V / WSL2 / Docker 会保留一段 TCP 端口，
    偶尔把 adb 默认的 5037 圈进去，adb 就永远起不来。
  → v1.6.1 启动时会自动换一个没被保留的端口，日志第一行会写
    “adb server 端口: xxxx”；正常应显示“默认端口可用”。
  → 若仍失败：关闭再打开本程序；还不行就重启一次电脑，
    或用管理员权限执行下面两条命令把端口范围恢复成 Windows 默认值：
        netsh int ipv4 set dynamicport tcp start=49152 num=16384
        net stop winnat && net start winnat
  → 查当前被系统保留的端口：netsh int ipv4 show excludedportrange protocol=tcp

· 配对成功了，但一直没连上，等了一分钟才有反应（v1.6.2 已给出提示和快捷键）
  → 配对和连接是两步。连接端口靠 mDNS 广播，通常要等 30–60 秒。
  → 界面现在会实时显示「已等 Ns / 最多 Ns」，不会让你以为失败。
  → 想秒连：手机「无线调试」主页面的 IP:端口 填到「已配对？直接连」，
    点「直接连接」。这条路不依赖 mDNS，一般 1–2 秒就连上。

================================================
【快捷键】（投屏窗口获得焦点时）
  Alt+O          手机黑屏（仍继续投屏，不锁屏）
  Alt+Shift+O    手机亮屏
  Alt+P          按一次电源键
  Alt+G          手机屏幕按 1:1 原始比例显示
  Alt+W          自适应窗口大小、去掉黑边
  F11            投屏窗口全屏
  Alt+F4         关闭投屏

================================================
【给 AI Agent 用：让电脑上的 Agent 操作手机】
 GUI 连好之后，Agent 可以复用同一条 adb 通道操作手机，
 人通过投屏窗口全程可见，随时能用鼠标接管。

 串号从 GUI「已发现设备」下拉框复制，adb 在 app\tools\adb.exe。
 常用命令（把 <serial> 换成实际串号）：

   adb -s <serial> exec-out screencap -p > screen.png     （截图给视觉模型看）
   adb -s <serial> shell uiautomator dump /sdcard/w.xml  （导出控件树，含文字+坐标）
   adb -s <serial> shell input tap 720 1600              （点击）
   adb -s <serial> shell input swipe 700 2200 700 900 300（滑动）
   adb -s <serial> shell input text "hello"              （输入英文）
   adb -s <serial> shell input keyevent 4                （返回键）

 建议循环：截图/控件树 → 模型判断下一步 → 点击/输入 → 再截图，
 直到任务完成。中文输入建议改用剪贴板或 ADBKeyboard。
 小米必须开「USB调试（安全设置）」才能点锁屏/支付密码界面。

 【内置 MCP Bridge（v1.6）】
 点 GUI 的「Agent 桥接：开」，程序即以 MCP Server 模式运行，
 外部 Agent 客户端可用 "手机投屏助手.exe --agent-bridge" 作为 server 接入，
 提供 snapshot/screenshot/tap/swipe/click_by_selector/shell 等 15 个工具。

 · 「暂停 Agent」按钮可随时冻结 Agent 操作，人直接接管投屏窗口
 · 命中密码/验证码/支付等敏感界面会弹窗请求人工批准，点「是」才继续
 · Agent 的每一步操作都会显示在 GUI 日志里，可随时查看
 · 也可用 --agent-bridge --http 8765 起 HTTP 调试接口
```
